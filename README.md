Interactive study tools and quizzes based on the official Anthropic Academy curriculum.

---

## 🚀 Propósito del Proyecto
Este repositorio contiene una colección de **cuestionarios interactivos** desarrollados para procesar, sintetizar y reforzar los conceptos clave de los cursos de Anthropic. El objetivo es transformar la teoría en una herramienta de aprendizaje práctica y técnica.

## 📚 Cursos en Progreso
A medida que complete mi formación en **Anthropic Academy**, se añadirán cuestionarios para los siguientes módulos:

### Fundamentos y Usuario Final
*   **Claude 101:** Uso básico, características principales y flujos de trabajo diarios.
*   **Introduction to Claude Cowork:** Trabajo colaborativo con archivos, plugins y proyectos.
*   **AI Fluency (Series):** Frameworks para educadores, estudiantes, ONGs y bases éticas de la IA.
*   **AI Capabilities and Limitations:** Fundamentos sobre cómo funciona la IA.

### Desarrollo y Programación
*   **Claude Code 101 & In Action:** Integración de herramientas de terminal y flujos de desarrollo.
*   **Building with the Claude API:** Implementación técnica y uso de modelos de Anthropic.
*   **Model Context Protocol (Intro & Advanced):** Construcción de servidores MCP, herramientas y recursos.
*   **Agent Skills & Subagents:** Configuración de instrucciones reutilizables y delegación de tareas.

### Infraestructura y Cloud
*   **Claude with Amazon Bedrock:** Implementación dentro del ecosistema de AWS.
*   **Claude with Google Cloud's Vertex AI:** Uso de modelos en la infraestructura de Google Cloud.

## 🛠️ Características Técnicas de los Quizzes
Cada cuestionario está diseñado con los siguientes estándares:
*   **Standalone HTML:** Archivos únicos con CSS y JavaScript integrados (sin dependencias externas).
*   **GitHub Pages Ready:** Optimizado para visualización directa desde el navegador.
*   **Diseño "Constitutional":** Estética inspirada en la interfaz de Claude (naranja y gris degradado).
*   **Feedback Detallado:** Explicaciones profundas basadas en la documentación oficial para cada respuesta.

## 📂 Cómo usar este repositorio
1.  Entra en la carpeta del curso correspondiente.
2.  Descarga el archivo `.html` deseado.
3.  Ábrelo en tu navegador favorito para comenzar el quiz.
